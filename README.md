# Video Downloader

Простое десктопное приложение для Windows с тёмным интерфейсом для скачивания видео по ссылке. Работает поверх [yt-dlp](https://github.com/yt-dlp/yt-dlp) и [FFmpeg](https://ffmpeg.org/), интерфейс построен на [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter).

## Возможности

- **Скачивание по ссылке** с любого сайта, который поддерживает yt-dlp
- **Очередь загрузок** с настраиваемым лимитом одновременных скачиваний (от 1 до 5)
- **Выбор максимального качества**: 4K (2160p), 2K (1440p), 1080p, 720p, 480p, 360p
- **Карточка для каждого видео**: обложка, название, бейдж с реальным качеством, прогресс-бар
- **Подробный статус**: проценты, размер файла, скорость в МБ/с и оставшееся время
- **Пауза и возобновление** загрузки (приостановка процесса yt-dlp через Windows API)
- **Автоматическая установка компонентов**: при первом запуске программа сама скачивает `yt-dlp.exe` и `ffmpeg.exe` с GitHub, а `yt-dlp` при каждом запуске обновляется до актуальной версии
- **Сохранение настроек** между запусками
- **Плавная боковая панель настроек**
- **Горячие клавиши работают на русской раскладке** (Ctrl+V / Ctrl+М, Ctrl+A / Ctrl+Ф)
- Видео и звук автоматически склеиваются в **MP4**

## Требования

- Windows 10 / 11 (используются `ctypes.windll` и `.exe`-версии утилит)
- Python 3.10+ (если запускаете из исходников)
- Доступ в интернет к `github.com` при первом запуске (для загрузки yt-dlp и FFmpeg)

Python-зависимости:

```
customtkinter
requests
Pillow
```

## Установка и запуск из исходников

```bash
git clone https://github.com/<kirito17717>/<VideoDownloader>.git
cd <ваш-репозиторий>

pip install customtkinter requests pillow

python main.py
```

При первом запуске внизу окна отобразится индикатор загрузки `yt-dlp` и `FFmpeg`. Пока компоненты не готовы, кнопка **«Скачать»** неактивна. Загрузка FFmpeg может занять некоторое время, это происходит один раз.

## Использование

1. Вставьте ссылку на видео в поле ввода (кнопка 📋, правый клик мыши или Ctrl+V).
2. Нажмите **«Скачать»** или клавишу Enter.
3. Следите за прогрессом в карточке видео. Кнопка ⏸ ставит загрузку на паузу, ✕ отменяет и удаляет карточку.
4. Готовый файл появится в выбранной папке.

Чтобы добавить сразу несколько видео, вставляйте ссылки по одной: они встанут в очередь и будут скачиваться в соответствии с лимитом одновременных загрузок.

## Настройки

Панель открывается кнопкой ☰ в левом верхнем углу.

| Параметр | Описание | По умолчанию |
|---|---|---|
| Папка для сохранения | Куда сохраняются скачанные файлы | `Загрузки` текущего пользователя |
| Максимальное качество | Верхняя граница разрешения видео | `1080p` |
| Одновременных загрузок | Сколько видео качается параллельно (1–5) | `2` |

Настройки сохраняются в файле `settings.json` рядом с программой:

```json
{
  "save_folder": "C:\\Users\\User\\Downloads",
  "quality": "1080p",
  "limit": 2
}
```

## Как это работает

Для каждой ссылки приложение:

1. Запрашивает метаданные через `yt-dlp --dump-json`, чтобы показать название, обложку и ожидаемое качество.
2. Запускает `yt-dlp` с форматом `bestvideo[height<=H]+bestaudio/best[height<=H]/best`, где `H` соответствует выбранному качеству, и склеивает результат в MP4 с помощью FFmpeg.
3. Разбирает вывод `yt-dlp` и обновляет карточку: прогресс, скорость, размер и итоговое качество.

Если видео недоступно в выбранном качестве, будет скачан лучший из доступных вариантов.

## Сборка в `.exe`

Установите PyInstaller и выполните сборку:

```bash
pip install pyinstaller

pyinstaller --noconsole --onefile --collect-all customtkinter main.py
```

Готовый файл появится в папке `dist/`. Утилиты `yt-dlp.exe` и `ffmpeg.exe` можно:

- **положить рядом с `.exe`**: тогда `yt-dlp` будет автоматически обновляться при каждом запуске;
- **вшить в сборку** через `--add-binary "yt-dlp.exe;."` и `--add-binary "ffmpeg.exe;."`;
- **не добавлять вовсе**: программа скачает их сама при первом запуске.
